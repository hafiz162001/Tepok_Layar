# 🦟 Nyamuk & Hewan Layar Desktop (Edisi Senjata & Pembesar!)

Aplikasi desktop serangga interaktif dengan **Pilihan Senjata Lengkap (Pistol, Raket Listrik, Palu, Tangan)** dan **Suara Hewan Nyata** yang berdengung langsung di layar Windows Anda!

---

## 🔫 Pilihan Senjata (Mengikuti Kursor Mouse):

Senjata akan mengikuti gerakan mouse Anda di layar, dan saat Anda klik kiri akan melakukan animasi serangan + efek suara + visual seru:

1. **🔫 Pistol (Handgun)**:
   - Suara tembakan mantap **"DORR!"**.
   - Efek kilatan moncong api (*muzzle flash*) + garis peluru laser kuning ke arah hewan!
2. **🏸 Raket Listrik / Tepokan**:
   - Suara sengatan voltase tinggi **"BZZT-PLAKK!"**.
   - Efek loncatan percikan kilat listrik (*electric sparks*).
3. **🔨 Palu (Heavy Hammer)**:
   - Suara hantaman logam berat **"DUKK!"**.
   - Efek retakan / bintang hantaman di layar.
4. **🖐️ Tangan (Hand Slap)**:
   - Suara tepokan renyah **"PLAAK!"**.

---

## 🐾 4 Pilihan Hewan Unik:

Setiap hewan memiliki tampilan, animasi, dan efek suara khasnya sendiri:
* 🦟 **Nyamuk**: Terbang meliuk-liuk di udara, sesekali hinggap di layar, dengungan nyaring (*nguuuung...*).
* 🕷️ **Laba-laba**: 8 kaki merayap menyeramkan dengan tanda jam pasir merah di punggungnya.
* 🦊 **Rubah (Fox)**: Bulu oranye-merah yang lincah berlari, dada putih, telinga lancip, ekor berbulu lebat bergoyang (*swishing tail*), suara langkah kaki & gonggongan manis (*yip*).
* 🦣 **Mammoth**: Tubuh purba berbulu lebat tebal, gading gajah melengkung raksasa, belalai panjang yang berayun, hentakan kaki gempa & raungan terompet purba!

---

## 🚀 Cara Menjalankan

Cukup klik dua kali:
```
run.bat
```
Atau jalankan via terminal:
```bash
python main.py
```

---

## ⌨️ Tombol Cepat (Keyboard Shortcuts)

| Tombol | Fungsi |
|---|---|
| **Klik Kiri Mouse** | Menembak / Menepuk dengan senjata aktif |
| **`Tab`** atau **`W`** | Ganti Senjata (Raket Listrik ➔ Pistol ➔ Palu ➔ Tangan) |
| **`1`, `2`, `3`, `4`** | **Tambah Hewan Baru** (1: +🦟 Nyamuk, 2: +🕷️ Laba-laba, 3: +🦊 Rubah, 4: +🦣 Mammoth) |
| **`C`** atau **`Backspace`** | Kurangi 1 Hewan (`-1`) |
| **`R`** | Reset ukuran semua hewan ke Level 1 (Normal) |
| **`Spasi`** | Bersihkan semua noda darah di layar |
| **`M`** | Sembunyikan / Munculkan Toolbar (Minimize) |
| **`ESC`** atau **`Q`** | Tutup dan keluar dari aplikasi |
